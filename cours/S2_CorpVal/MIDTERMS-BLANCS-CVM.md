## 0. LA MÉCANIQUE À RETENIR (15 lignes, rien d'autre)

1. FCFF → **WACC** → **EV** · FCFE → **Ke** → **Equity** · Dividende → **Ke** → **Equity**. Jamais croiser.
2. Equity = EV − debt + cash excéd. + actifs non-op (− NCI). Après FCFE : **rien à soustraire**.
3. NOPAT = EBIT normalisé × (1−t). IC = actifs op − passifs op (cash excéd. **dehors**). ROIC = NOPAT/IC.
4. Normaliser = récurrence économique : one-off vrai → add-back ; gain non-op → retirer ; « one-off » **annuel** → garder.
5. FCFF = NOPAT + D&A − CapEx − ΔNWC. EBITDA ≠ FCFF.
6. g = RR × ROIC → RR stable = g ÷ ROIC. Croissance sans réinvestissement = incohérent.
7. TVₙ = **FCFFₙ₊₁** ÷ (WACC − g) ; WACC > g ; TVₙ discountée **n** fois.
8. TV grosse (70-90 %) = normal → on inspecte g/ROIC/marge, on ne rejette pas.
9. Multiple implicite = TV ÷ EBITDA terminal = **cross-check**, pas la valo.
10. Gordon : P₀ = **D₁**/(Ke−g), D₁ = D₀(1+g). Zéro croissance : P₀ = D/Ke.
11. g soutenable = rétention × ROE ; rétention = 1 − payout.
12. Multi-stage : Pₙ = Dₙ₊₁/(Ke−g) ; Pₙ discounté n fois ; ke qui change → facteurs cumulés.
13. WACC : poids de **marché** ; Rf dans la **devise** des CF ; Kd **forward** ; beta **bottom-up** (unlever pairs, médiane, relever cible).
14. R&D capitalisée : EBIT adj = EBIT + R&D − amort. R&D ; le FCFF ne change (quasi) pas = bénéfice analytique.
15. Horizon explicite : assez long pour atteindre un état **mature** (marge/ROIC/g stables).
