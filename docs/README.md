# Assessment Trainer

Plateforme d'entraînement aux tests d'aptitude utilisés dans les processus de sélection bancaires :
raisonnement numérique et verbal, raisonnement déductif et inductif, switch challenge, capacité de
concentration, efficacité d'apprentissage, mémoire de travail, traitement de l'information,
raisonnement mécanique, questionnaires de comportement professionnel et de motivation.

## Accès

Le site s'ouvre sur un écran d'accès : **code d'accès + prénom**.
Chaque prénom crée un **profil séparé** avec son propre historique (tentatives horodatées au jour et
à l'heure, progression, feedback). Pratique pour partager la plateforme sans mélanger les résultats.

## Contenu

- **13 sections + 1 simulation complète** en conditions d'examen.
- **Banques figées** : mêmes items à chaque session (on mesure la régularité, pas la chance).
- **Batterie anglaise illimitée** : passages générés dans un style invariant.
- **Feedback détaillé question par question** : votre réponse, la réponse correcte, le temps, l'heure
  et l'explication, avec export CSV par session.
- **Progression** : sessions, précision, tendances, heatmap 30 jours, export JSON.
- **Mode examen** : chrono par item, correction en fin de session.

## Confidentialité

Tout est stocké **localement dans le navigateur** (`localStorage` + `IndexedDB`) : aucune donnée n'est
transmise à un serveur, aucun compte n'est requis. Le code d'accès est modifiable dans les réglages.
