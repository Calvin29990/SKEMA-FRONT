# Assessment Trainer

Plateforme d'entraînement aux tests d'aptitude utilisés dans les processus de sélection bancaires
(raisonnement numérique et verbal, raisonnement déductif et inductif, switch challenge,
capacité de concentration, efficacité d'apprentissage, traitement de l'information,
raisonnement mécanique, questionnaires de comportement professionnel).

## Utilisation

Ouvrez simplement le site : `index.html` (aucune installation, aucune dépendance).
Tout est statique et fonctionne hors ligne après le premier chargement
(seule la police Google Fonts est chargée depuis le réseau).

## Contenu

- **13 sections + 1 simulation complète** en conditions d'examen.
- **Banques figées** : mêmes items à chaque session (mesure de la régularité).
- **Batterie anglaise illimitée** : passages générés dans un style invariant.
- **Progression** : sessions, précision, tendances, heatmap 30 jours, export JSON.
- **Feedback** : sections fragiles, régularité des temps de réponse, journal des erreurs.

## Confidentialité

Tout est stocké **localement dans le navigateur** (`localStorage` + `IndexedDB`) :
aucune donnée n'est transmise à un serveur, aucun compte n'est requis.
