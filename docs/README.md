# Carte interactive — risque de change & football

Page publiée : **index.html** (autonome, sans dépendance externe).

- `index.html` : carte SVG de France (densité de sièges par région, agrégée) + clubs de Ligue 1
  dont le partenariat FX a été **annoncé publiquement**. Les entreprises ne sont jamais nommées.

Généré par `build_map.py` (matplotlib non requis ; openpyxl pour le classeur).
