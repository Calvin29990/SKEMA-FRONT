# Assessment Trainer

Plateforme d'entraînement aux tests d'aptitude utilisés dans les processus de sélection bancaires :
raisonnement numérique et verbal, déductif et inductif, switch challenge, concentration, efficacité
d'apprentissage, mémoire de travail, traitement de l'information, raisonnement mécanique,
questionnaires de comportement professionnel et de motivation.

## Accès

Code d'accès + prénom. Historique horodaté, progression et feedback detaille, conserves
uniquement dans le navigateur de l'appareil.

## Contenu personnel

La tache Numerical Reasoning accepte un fichier JSON local (bouton
« Ouvrir mon fichier ») : il est lu sur l'appareil, jamais envoye ni publie.

## Langues

Interface et feedback en **français, anglais, espagnol et portugais** (sélecteur en haut à droite).

## Contenu

- 13 sections + 1 simulation complète en conditions d'examen
- Banques figées (mêmes items à chaque session) et batterie anglaise illimitée
- Feedback détaillé question par question (réponse donnée, réponse correcte, temps, heure, explication) + export CSV
- Progression : sessions, précision, tendances, heatmap 30 jours, export JSON

## Confidentialité

Tout est stocké localement dans le navigateur (`localStorage` + `IndexedDB`). Aucune donnée transmise.
