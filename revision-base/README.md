# Révision : tests Deloitte Maki

Ce dossier couvre les 4 épreuves de votre liste, avec des cours de base et 30 questions d'entraînement. Les questions sont originales. Elles ne reprennent aucun contenu réel de test.

## Mode d'emploi

1. Lisez un cours (environ 30 minutes).
2. Répondez aux questions correspondantes dans `questions.md`, sans regarder les réponses.
3. Corrigez dans `reponses.md`, et notez ce que vous n'avez pas su.
4. Refaites les questions ratées deux jours plus tard.
