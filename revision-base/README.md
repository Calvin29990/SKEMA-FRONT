# Révision de base : finance de marché, dérivés, produits structurés, middle office

Ce dossier contient 4 cours courts et 30 questions classiques, avec leurs réponses.

## Mode d'emploi

1. Lisez un cours (1 par jour, environ 30 minutes).
2. Répondez aux questions correspondantes dans `questions.md` **sans regarder** les réponses.
3. Corrigez dans `reponses.md`. Notez ce que vous n'avez pas su et revoyez-le.
4. Refaites les questions ratées deux jours plus tard.
