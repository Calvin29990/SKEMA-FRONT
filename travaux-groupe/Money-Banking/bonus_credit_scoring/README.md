# Bonus 2 — Credit Bureaus deck

Editable six-slide PowerPoint template for Team 5's optional **Credit Bureaus** exercise.

- `output/BONUS-2-CREDIT-BUREAUS-TEAM-5.pptx` — editable PowerPoint deck
- `../BONUS-2-CREDIT-SCORING.md` — detailed content draft and source notes
- `build_bonus_credit_bureaus_deck.py` — generator

The deck uses only the supplied public positioning and official source URLs. It deliberately avoids unsupported statistics, market rankings, score ranges and founding dates. The final slide contains the source list for verification before submission.
