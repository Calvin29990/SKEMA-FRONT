# MÉMO 03 — RAISONNEMENT VERBAL (49 affirmations, 12:00)

> Même mécanique que le numérique, mais sur **6 fiches de textes** (GROUPE, STRATÉGIE, PRINCIPES,
> PRODUITS, IMPLANTATIONS, DIRECTION) au lieu de 6 feuilles de chiffres. 49 affirmations
> TRUE / FALSE / CANNOT SAY, 12 minutes, navigation libre entre fiches.

## 1. Différence avec le numérique (ta question)
| | Numérique | Verbal |
|---|---|---|
| Support | tableaux / graphiques | **textes** d'entreprise |
| Effort | calcul mental + lecture de figures | **lecture précise** + repérage |
| Piège n°1 | unités, CANNOT SAY par absence de donnée | **mots absolus** (all, always, only, exclusively) + CANNOT SAY par absence dans le texte |
| Vitesse | 1 item = 1 calcul ou 1 lecture | 1 item = 1 repérage dans 1 fiche |

Le verbal est **plus rapide à condition de scanner** : lis l'affirmation, identifie la fiche (par le sujet :
structure→GROUPE, coûts/marketing→STRATÉGIE, RH/formation→PRINCIPES, marques→PRODUITS, pays/usines→
IMPLANTATIONS, comités/board→DIRECTION), puis cherche **le mot-clé**, pas la phrase entière.

## 2. Ce qui est évalué / valorisé
Comprendre **exactement** ce que dit un texte, sans sur-interpréter. Les leurres classiques :
- **Généralisation abusive** : « always / exclusively / only » alors que le texte dit « at least / mainly ».
- **Inversion** : « external before internal » alors que c'est l'inverse.
- **Confusion de périmètre** : fully consolidated vs equity method ; UK vs abroad.
- **CANNOT SAY** quand le texte ne donne **pas** la donnée (profitabilité d'une marque achetée, fréquence
  d'audit, date de fin d'une exception).

## 3. Vitesse / repères humains (indicatif, non vérifié)
49 en 12 min ≈ 15 s/item. Naïf : 15-20 items ; entraîné : 28-36 ; très entraîné : 40+. Toi : viser 30-35
à ≥ 90%. Les items « stated » (TRUE direct) doivent partir en 6-8 s.

## 4. Astuces
1. **Mots absolus = alerte** : vérifie systématiquement ; souvent FALSE.
2. **Chiffres dans le texte** = cadeau : « one eighth » = 12.5% ; « 2.4 days » ; « 34 countries » ; « 4+2+2+1=9 ».
3. **CANNOT SAY** dès que l'affirmation ajoute une info absente (profitabilité, fréquence, date, export flows).
4. Ne relis **jamais** toute la fiche : repère le paragraphe par le premier mot en gras.

- « fully consolidated vs equity method » ; « internal before external » ; « single grade » ;
  « 3 continents pas 4 » ; « Manchester + Gdansk » ; « 4+2+2+1=9 » ; « 6 vs 4 brands » ; « outside Europe ».
