# MÉMO 03 — RAISONNEMENT VERBAL (49 affirmations, 12:00)

> 🏋️ **Avant le test, entraîne-toi :** [EX-03 · 60 items](exos/exos-03-verbal.md) — 10 textes × 6 affirmations.
> Chaque item donne la réponse **et le piège à éviter** : lis le piège même quand tu as juste.

> Même mécanique que le numérique, mais sur **6 fiches de textes**. 49 affirmations
> TRUE / FALSE / CANNOT SAY, 12 min, navigation libre. Chaque item indique **en gras** le passage exact de
> la fiche à regarder.

## 1. Différence avec le numérique
| | Numérique | Verbal |
|---|---|---|
| Support | tableaux/graphes | **textes** d'entreprise |
| Effort | calcul | **lecture précise + repérage** |
| Piège n°1 | unités, CANNOT SAY par donnée absente | **mots absolus** (all/always/only/exclusively) + CANNOT SAY par absence |
| Vitesse | 1 item = 1 calcul/lecture | 1 item = 1 repérage dans 1 fiche |

## 2. Repères humains (indicatif, non vérifié)
49 en 12 min ≈ 15 s/item. Naïf 15-20 · entraîné 28-36 · très entraîné 40+. Toi : 30-35 à ≥ 90%.

## 3. LES 6 FICHES (résumé fidèle — le mot en tête = ancre de repérage)
- **GROUPE** : UK, listé **Londres** ; 3 divisions ; **11 filiales 100% + 4 majoritaires (51-90%) = consolidées** ;
  **3 associées (20-49%) = equity method** ; minoritaires **présentés séparément** ; finance/legal/**internal audit au niveau groupe**.
- **STRATÉGIE** : marques milieu/haut de gamme ; croissance **organique + acquisitions sélectives** ;
  **cession du private label Foods** ; overheads **−1/8 (~12.5%) en 2 ans** ; marketing **maintenu ~9%** ;
  services partagés **centralisés dans 2 centres**.
- **PRINCIPES** : matières premières **traçables/certifiées** fin de période ; rapport durabilité **annuel revu par audit committee** ;
  **postes internes annoncés groupe 2 semaines avant externe** ; formation **2.4 j** ; **grade structure unique**.
- **PRODUITS** : Home Care **4 marques** ; Personal Care **6 marques** dont **Corline (acquise)** ; Foods **3 marques** ;
  licence **hors Europe**, revenu **dans la division propriétaire**.
- **IMPLANTATIONS** : **9 usines** (UK 4, Europe 2, N.Am 2, Australie 1) ; **pas d'usine en Asie/Am.Sud** ;
  centres **Manchester + Gdansk** ; vend dans **34 pays** ; UK = **propres dépôts** ; N.Am = **joint venture** ;
  ailleurs distributeurs indépendants.
- **DIRECTION** : **executive board = 5** (CEO, CFO, 3 CEOs divisionnels) ; **chairman supervisory PAS membre** ;
  **audit committee = 3, tous non-exécutifs** ; **remuneration = 4 dont 1 exécutif (exception transitoire)**.

## 4. Astuces
1. **Mots absolus = alerte** (often FALSE). 2. **Chiffres = cadeau** (one eighth=12.5% ; 2.4 ; 34 ; 4+2+2+1=9).
3. **CANNOT SAY** si l'affirmation ajoute une info absente. 4. Ne relis pas toute la fiche : vise le paragraphe.
