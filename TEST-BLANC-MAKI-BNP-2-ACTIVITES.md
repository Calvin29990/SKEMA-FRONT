> *Total : 4,2 + 3,5 + 2,8 + 1,5 = **12,0 M€**.* Le piège est d'oublier une classe d'actifs dans le total.

**Q4 → C (1 000 000 €).** 250 000 000 × 0,004 = **1 000 000 €**.

**Q5 → A (4).** Alternance : **+3, −2, +3, −2, +3, −2.** …1, 4, 2, 5, 3, 6, **4**.

**Q6 → A (A).** Contrainte : A avant B avant C, et D en dernier. → **A, B, C, D**. Dernier = D ✅, B avant C ✅, B après A ✅.

**Q7 → B.** *Certains produits sont des HY → ces produits sont plus risqués que les obligations d'État.*
> ⚠️ A est faux (on ne sait pas pour les autres produits du fonds), C est faux, D est faux (on ne sait rien des autres).

**Q8 → C (3,5 %).** Fisher approché : nominal ≈ réel + inflation = 1,4 + 2,1 = **3,5 %**.
> *Exact : 1,021 × 1,014 = 1,03529 → 3,53 %. La question dit « approximatif ».*

**Q9 → B.** **② contredit ①** (tous vs aucun) **et contredit ③** (③ donne un client qui a signé, ② dit qu'aucun n'a signé).
> *① et ③ sont compatibles : si tous ont signé, alors Z a signé.*

**Q10 → B (−4 %).** 0,80 × 1,20 = **0,96** → −4 %.
> *Ne jamais additionner les pourcentages : ils se multiplient.*

**Q11 → B (A + C).** A+C = 6 + 4 = **10 M€** (le budget exact) → NPV = 4 + 2 = **6**. B+C = 9 → NPV 5. A seul = NPV 4. **A+C gagne.**
> *Le piège : choisir A+B (coût 11) → dépasse le budget.*

**Q12 → A (4,6 %).** 0,60 × 3 % + 0,40 × 7 % = 1,8 + 2,8 = **4,6 %**.

**Q13 → A.** *« Monte le matin → calme l'après-midi. »* Non-calme l'après-midi → **le marché n'a pas monté le matin.**
> ⚠️ **B est faux** : « ne pas monter » n'est pas « baisser ». C'est l'erreur classique de surinterprétation.

**Q14 → B (400).** 3 200 × 25 % = 800 électroniques. La moitié → **400**.
