## B. Frenglish SKEMA → anglais natif du desk

| Frenglish courant | ✅ Natif |
|---|---|
| « I propose you to… » | **I'd suggest we… / May I suggest…** |
| « make a meeting » | **set up / arrange a meeting** |
| « I am agree » | **I agree** |
| « explain me » | **walk me through it / explain it to me** |
| « We can see that there is… » (réflexe PPT) | **The data shows… / The chart indicates…** |
| « in the actual context » | **in the current environment / in today's climate** |
| « more and more important » | **increasingly important** |
| « Globally, … » | **Overall, … / Broadly speaking, …** |
| « I have 23 years » | **I'm 23** |
| « It depends of… » | **It depends on…** |
| « discuss about » | **discuss** (transitif) |
| « I go at the office » | **I'm going to the office** |
| « very very important » | **critical / pivotal / business-critical** |
| « big » (montant) | **sizable / substantial / material** |
| « It's a lot of money » | **That's a significant sum** |
| « the society » (entreprise) | **the company / the firm** (a society = une association) |
| « actually » (comme « actuellement ») | **currently / at the moment** |
| « of course » (partout) | **certainly / absolutely / by all means** (dosé) |
| « I think it's good » (paresseux) | **My view is… / I'd argue that… / That said, …** |
| « the numbers are like that » | **the figures bear this out / the numbers stack up** |
| « We need to see » | **Let's look into it / I'll dig into the numbers** |
| « I didn't know » (faible) | **That's a gap I've since filled — here's what I found** (turn it positive) |

## C. Les mots baguette à bannir de l'oral interview
- *« euh »* → *well / so / hmm let me think*
- *« voilà »* → *that's it / so essentially…*
- *« enfin »* → *I mean / ultimately*
- *« quoi »* (fin de phrase) → rien. Silence net.
- *« normalement »* → *normally ✅* mais « normally we would » ≠ « normally » comme interjection

## D. Spelling UK vs US (pour tes emails de job simulation)
- UK : **colour, analyse, organisation, centre, programme** (sauf *computer program*), licence (n.) / license (v.)
- Tes écrits Barclays = UK English systématiquement. Le correcteur de Word : à régler sur *English (United Kingdom)*.
